# 文献资料夹说明

本文件夹用于保存论文写作过程中使用的公开文献、指南网页、官方说明页和 PubMed 题录页。

## 文件夹结构

- `references_master.md`：论文参考文献总表，当前整理 70 条核心文献。
- `pdf/`：已成功下载的公开 PDF 全文，当前 18 个。
- `html/`：指南网页、官方说明页或 PubMed 摘要页，当前 30 个。
- `metadata/download_log.csv`：下载记录，包括来源 URL、下载状态、文件大小和本地路径。

- 老年用药/指南：`AGS_Beers_Criteria_2023.pdf`、`Chinese_Adult_Insomnia_Guideline.html`、`European_Insomnia_Guideline_2023.pdf`、`AASM_Pharmacologic_Treatment_Chronic_Insomnia_2017.pdf`
- 唑吡坦/Z-drugs 安全性：`FDA_Zdrugs_Boxed_Warning_Complex_Sleep_Behaviors_2019.html`、`FDA_Zolpidem_Next_Morning_Impairment_2013.pdf`、`DailyMed_Zolpidem_Tartrate_Label.pdf`

- FAERS/药物警戒方法：`FDA_Data_Mining_White_Paper.pdf`、`Frontiers_SRS_Drug_Drug_Interaction_Methods_2019.pdf`、`READUS_PV_Reporting_Disproportionality_2024.html`

## 说明

部分文献没有直接保存 PDF，是因为全文可能需要出版社权限或学校数据库访问。此类文献暂时保存 PubMed、指南或官方网页页面，后续可用 DOI 或 PMID 在学校图书馆数据库中下载。

正文引用格式将采用右上角上标形式，例如：`<sup>[1]</sup>`。后续生成 Word 时会转换为上标引用样式。
